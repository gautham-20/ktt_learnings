1. What is Bootstrap?

Definition: Bootstrap is a front-end framework used to create responsive, mobile-first websites quickly. It provides ready-made CSS classes and optional JavaScript components.

Example syntax

<button class="btn btn-primary">
    Click Me
</button>

Uses: Responsive layouts, buttons, forms, tables, navigation bars, cards and other interface components.

2. CDN Link

Definition: A CDN (Content Delivery Network) allows you to load Bootstrap files from a hosted server instead of downloading and storing them locally.

Bootstrap 5 CSS

<link
 href="https://cdn.jsdelivr.net/npm/bootstrap@5.0.2/dist/css/bootstrap.min.css"
 rel="stylesheet">

Bootstrap 5 JavaScript bundle

<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.0.2/dist/js/bootstrap.bundle.min.js">
</script>
The CSS link provides styling. The JavaScript bundle is needed for interactive components such as dropdowns, carousels and accordions. Internet access is needed for these CDN files.

4. Grid Layout

Definition: The Bootstrap grid system arranges content into responsive rows and columns. Bootstrap 5 uses a 12-column grid.

Syntax

<div class="container">
    <div class="row">
        <div class="col-md-6">Left</div>
        <div class="col-md-6">Right</div>
    </div>
</div>

Common breakpoints:

ClassBreakpoint
col-All screen sizes
col-sm-576px and above
col-md-768px and above
col-lg-992px and above
col-xl-1200px and above
col-xxl-1400px and above

5. Row and Column

Definition: A row groups columns horizontally. Columns hold the content inside the grid.

Syntax

<div class="container">
    <div class="row">
        <div class="col-4">Column 1</div>
        <div class="col-4">Column 2</div>
        <div class="col-4">Column 3</div>
    </div>
</div>

Each col-4 occupies 4 of the 12 grid columns, giving three equal-width columns.

6. Padding

Definition: Padding is the space inside an element, between its content and its border.

Syntax

p-3   /* padding on all sides */
pt-3  /* padding on top */
pb-3  /* padding on bottom */
ps-3  /* padding at start */
pe-3  /* padding at end */
px-3  /* horizontal padding */
py-3  /* vertical padding */

Bootstrap 5 spacing utilities generally use values from 0 to 5.

<div class="p-3 bg-light">
    Content with padding
</div>

7. Margin

Definition: Margin is the space outside an element's border, separating it from other elements.

Syntax

m-3   /* margin on all sides */
mt-3  /* margin top */
mb-3  /* margin bottom */
ms-3  /* margin start */
me-3  /* margin end */
mx-3  /* horizontal margin */
my-3  /* vertical margin */
mx-auto /* horizontal auto margins */
<div class="mt-3 mb-4">
    Content with margins
</div>

8. Button

Definition: Bootstrap buttons provide ready-made styles for clickable actions.

Syntax

<button class="btn btn-primary">Primary</button>
<button class="btn btn-success">Success</button>
<button class="btn btn-danger">Delete</button>
<button class="btn btn-warning">Warning</button>
<button class="btn btn-outline-primary">Outline</button>

9. Table

Definition: A table displays data in rows and columns. Bootstrap's table class adds basic table styling.

Syntax

<table class="table">
    <thead>
        <tr>
            <th>Name</th>
            <th>Age</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>Arun</td>
            <td>20</td>
        </tr>
    </tbody>
</table>

10. Table Striped

Definition: Alternating row backgrounds make table data easier to read.

<table class="table table-striped">
    ...
</table>

Note: table-striped is available in Bootstrap 3 and Bootstrap 5.

11. Table Condensed

Definition: A condensed table uses less vertical space by reducing cell padding.

Bootstrap 3 syntax

<table class="table table-condensed">
    ...
</table>

Bootstrap 5 equivalent

<table class="table table-sm">
    ...
</table>
Bootstrap 5 uses table-sm instead of table-condensed.

12. Table Hover

Definition: The hover style highlights a row when the mouse pointer moves over it.

<table class="table table-hover">
    ...
</table>

13. Table Bordered

Definition: Adds borders around the table and its cells.

<table class="table table-bordered">
    ...
</table>

Other useful table classes include table-dark, table-striped, table-hover and table-responsive.

16. Basic Form Example

Definition: A basic form arranges labels and input fields vertically.

<form>
    <div class="mb-3">
        <label for="name" class="form-label">Name</label>
        <input type="text" id="name" class="form-control">
    </div>

    <div class="mb-3">
        <label for="email" class="form-label">Email</label>
        <input type="email" id="email" class="form-control">
    </div>

    <button class="btn btn-primary" type="submit">
        Submit
    </button>
</form>

17. Inline Form

Definition: An inline form places multiple form controls on the same horizontal line when space permits.

Bootstrap 3 syntax

<form class="form-inline">
    <input type="text" class="form-control"
           placeholder="Name">
    <button class="btn btn-primary">Submit</button>
</form>

Bootstrap 5 syntax

<form class="row row-cols-lg-auto g-3 align-items-center">
    <div class="col-12">
        <input class="form-control" placeholder="Name">
    </div>
    <div class="col-12">
        <button class="btn btn-primary">Submit</button>
    </div>
</form>
Bootstrap 5 removed the old form-inline class. Grid and flex utilities can be used to arrange controls horizontally.

18. Horizontal Form

Definition: A horizontal form places labels and input fields side by side in the same row.

Bootstrap 3 syntax

<form class="form-horizontal">
    <div class="form-group">
        <label class="control-label col-sm-2">Name</label>
        <div class="col-sm-10">
            <input class="form-control" type="text">
        </div>
    </div>
</form>

Bootstrap 5 syntax

<div class="row mb-3">
    <label class="col-sm-2 col-form-label">Name</label>
    <div class="col-sm-10">
        <input class="form-control" type="text">
    </div>
</div>

19. Static Control

Definition: A static control displays a value as text rather than as an editable input field.

Bootstrap 3 syntax

<p class="form-control-static">
    student@example.com
</p>

Bootstrap 5 syntax

<p class="form-control-plaintext">
    student@example.com
</p>

20. Focus State

Definition: The focus state indicates that an input field is currently selected or ready for keyboard input.

<input type="text" class="form-control"
       placeholder="Click or tab here">

Bootstrap styles focused inputs automatically. The browser can also move focus using the Tab key.

21. Disabled State

Definition: A disabled field cannot normally be edited or focused by the user.

<input type="text" class="form-control"
       value="Not available" disabled>

<button class="btn btn-primary" disabled>
    Submit
</button>

22. Readonly State

Definition: A readonly input displays a value that the user cannot edit, but its value can still be submitted with a form.

<input type="text" class="form-control"
       value="Arun" readonly>

Cannot normally be edited or focusedCannot be edited

23. Responsive Images

Definition: Responsive images scale to fit their container without overflowing it.

Syntax

<img src="photo.jpg"
     class="img-fluid"
     alt="Landscape">

In Bootstrap 5, img-fluid applies max-width: 100% and height: auto.

24. Image Shapes

Definition: Image shape classes change how an image's corners and outline appear.

Syntax

<img src="photo.jpg" class="rounded" alt="Photo">

<img src="photo.jpg" class="rounded-circle" alt="Circle">

<img src="photo.jpg" class="img-thumbnail" alt="Thumbnail">
ClassEffect
roundedRounded corners
rounded-circleCircular appearance for a suitable square image
img-thumbnailThumbnail with border and padding

25. Accordion

Definition: An accordion is a component that expands and collapses sections of content.

Bootstrap 5 syntax

<div class="accordion" id="myAccordion">
    <div class="accordion-item">

        <h2 class="accordion-header" id="headingOne">
            <button class="accordion-button"
                    type="button"
                    data-bs-toggle="collapse"
                    data-bs-target="#collapseOne"
                    aria-expanded="true"
                    aria-controls="collapseOne">
                What is Bootstrap?
            </button>
        </h2>

        <div id="collapseOne"
             class="accordion-collapse collapse show"
             aria-labelledby="headingOne"
             data-bs-parent="#myAccordion">

            <div class="accordion-body">
                Bootstrap is a front-end framework.
            </div>
        </div>

    </div>
</div>
The example requires Bootstrap CSS and the Bootstrap JavaScript bundle to expand and collapse. HTML and CSS alone do not provide Bootstrap's JavaScript accordion behavior.

26. ARIA

Definition: ARIA stands for Accessible Rich Internet Applications. It adds accessibility information to elements so assistive technologies can understand their roles and states.

Common attributes

aria-label="Close"
aria-expanded="false"
aria-controls="menu"
aria-hidden="true"
role="button"

Example

<button type="button"
        aria-label="Close dialog">
    X
</button>

Use native HTML elements whenever possible. ARIA adds accessibility information but does not automatically create keyboard behavior or functionality.

27. Card

Definition: A card is a flexible content container used to display related information such as images, headings, text and buttons.

Syntax

<div class="card" style="width: 18rem;">
    <img src="japan.jpg" class="card-img-top" alt="Japan">

    <div class="card-body">
        <h5 class="card-title">Japan</h5>
        <p class="card-text">
            Discover Japan.
        </p>
        <a href="#" class="btn btn-primary">
            Learn More
        </a>
    </div>
</div>
